# Dental AI landing page

## Objective
Generate qualified demo requests from multinational dental practices.

## Source-of-truth inputs
Approved project brief and supplied brand assets.

## Locked decisions
Copy and clinical claims remain unchanged.

## Visual concept
Frosted clinical confidence with diagnostic imagery.

## Typography
Space Grotesk display and DM Sans body.

## Colour tokens
Cloud background, ink foreground, and diagnostic blue accent.

## Layout system
Twelve-column desktop grid with responsive gutters.

## Section map
Hero, proof, product, capabilities, compliance, integration, and CTA.

## Imagery and iconography
Panoramic scan imagery and one consistent outlined icon family.

## Components and interactions
Functional navigation, demo form, film control, and visible states.

## Motion system
Precise, calm, and assured motion uses CSS for state feedback and the existing React motion library for short section choreography. Entrances use restrained 16–24 px travel, consistent easing, and limited stagger. Reduced-motion users receive the final state immediately with essential feedback preserved.

## Responsive transformations
Two-column hero becomes a single-column narrative at mobile widths.

## Accessibility
Semantic landmarks, keyboard access, visible focus, and reduced motion.
